# Changelog

## 0.1.0 — 2026-10-08

- Strict ID-paired binary evaluation comparisons from UTF-8 CSVs.
- Overall and declared slice transitions with exact one-sided paired tests.
- Holm correction across every group with sufficient support.
- A transparent configurable regression gate and separate error exit status.
- One offline interactive HTML report, JSON and Markdown exports, and losses CSV.
- Mean cost and latency summaries, input fingerprints and reproducible synthetic data.
- A Python library, CLI, and dependency-free GitHub composite action.

The project currently supports independent binary evaluation cases. Clustered uncertainty, continuous-score comparisons and automatic slice discovery are not included.
